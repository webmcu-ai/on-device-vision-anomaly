Nothing loaded yet. Pick the SD card root (the folder that contains images/ and header/), or load a zip of it.

2. Classes and data

The firmware has exactly one class (NUM_CLASSES is compile-time), so there is no add/remove class. It trains only on the normal folder. The optional folder is browser-only: images that should look ANOMALOUS, used just to measure detection. The firmware ignores that folder.
